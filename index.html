Final Year Design Project

PrivAdapt

On-device language intelligence, built for real constraints

PrivAdapt: A Privacy-Oriented, Self-Recalibrating On-Device LLM System with Compute-Adaptive Routing

A framework running 4-bit quantized 1B and 3B language models on a CPU-only laptop for health and agriculture queries. A lightweight router sends each query to a specialized local model, a fused model, the general local model, or a privacy-controlled server fallback.

Team of six · United International University, CSE · Supervisor: Ms. Sadia Islam, Assistant Professor

  • On-Device LLM
  • Quantization
  • Routing
  • Privacy
  • Distribution Shift

Contributions

  1. Self-recalibrating routing detects distribution shift with maximum mean discrepancy and re-fits behind a validation gate.
  2. Configurable privacy levels govern what the server payload may contain.
  3. Compute-adaptive switching chooses between 1B and 3B models using query features and live device telemetry.

Evaluated results

three-class routing accuracy on 150 queries
19.8%

2.23×

0 / 450

In a 500-query drift simulation, recalibration reduced post-shift false escalation from 1.000 to 0.693 (McNemar p = 1.9 × 10−22).
